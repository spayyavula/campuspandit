# CampusPandit

White-label coaching center platform for JEE & NEET prep institutes — React 18 + Vite 5 + TypeScript PWA, AWS-migrated backend (Lambda + RDS Proxy + API Gateway HTTP). See [CONTEXT.md](CONTEXT.md) for the domain glossary.

## Agent skills

### Issue tracker

GitHub Issues at `github.com/spayyavula/campuspandit`, managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical 5-role vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`); `wontfix` already exists on the repo, the other four will be auto-created on first use. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` at repo root. `docs/adr/` will be created when the first ADR lands. See `docs/agents/domain.md`.
